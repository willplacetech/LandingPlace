Gerenciar logotipos

Prepare novas marcas para o carrossel da PlaceTech. As imagens são ajustadas para um mesmo espaço visual sem distorcer o original.

Publicação manual

Este site não tem servidor. Depois de adicionar os logos, baixe o manifesto JSON, substitua assets/client-logos.json no projeto e publique o site novamente. O rascunho local aparece apenas neste navegador.

Acesso do administrador

No primeiro acesso, crie uma senha para este navegador. Ela não é enviada nem salva no código do site.

A senha é uma barreira casual, não uma autenticação segura: o HTML/JavaScript do site é público e pode ser inspecionado ou alterado.
